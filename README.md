## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   # or
   npm run dev
   ```

A specific Node.js version is not defined in the project, but using an up-to-date LTS version of Node.js is recommended.
